最初はHTMLを手書きしていた。テキストエディタでタグを打って、FTPでアップして、というやつ。今思えばよくやっていたなと思うけど、当時はそれが当たり前だったし、むしろ楽しかった気もする。 `<html>` とか `<table>` とか、ちまちまタグを書きながら「これでちゃんと表示されるかな」とブラウザでリロードする、あの感じ。デザインも全部手作りで、我ながら素朴なものだったけど、自分で作った実感があってよかった。

その後、ブログエンジンをいくつか渡り歩いた。PyBlosxom を使っていた時期もあって、Python で書かれた軽量なやつ。テーマやプラグインを自分でいじれるのが気に入っていた。コメント欄のスパム対策や、シンタックスハイライトの設定など、今となってはどうでもいいような細部に妙に時間をかけていた記憶がある。そこからいろいろあって、今は Hugo に落ち着いている。静的サイトジェネレーターなので速いし、Emacs との相性も悪くない。

書いていることは昔から一貫していて、要は「自分が触っているもの」の記録。2009年ごろは Gentoo Linux で Live CD を作っていたり、awesome → xmonad とウィンドウマネージャを渡り歩いていたり。当時の自分は、わりとやんちゃだったなと思う。Guruplug とか EeePC とか、懐かしい単語が記事に並んでいる。あの頃は「小さくて低消費電力の Linux マシン」のようなものに、妙にテンションが上がっていた。今でいう Raspberry Pi みたいな感覚だったのかもしれない。

昔の記事は全部残っているわけではない。手書きHTMLの頃のものは断片的にしか残っておらず、残っているものから起こしている状態。ちゃんとバックアップしておけばよかったとは思うけれど、まあ、それでもいいかなとも思っている。完璧なアーカイブではなく、残っていたものが残っている、くらいの温度感で。むしろ抜けている部分があるからこそ、「あの時期はそういう感じだったんだろうな」と想像する余地があって、それはそれでいい気がしている。

更新頻度は正直低い。気が向いたときや、まとめたいことができたとき、そのくらい。日記代わりにせっせと書くつもりはないし、PV稼ぎにもそれほど興味はない。書きたいから書く、それだけ。下手に「週1更新」なんて決めてしまうと途端につらくなるのが目に見えているので、最初からそういうルールは作っていない。

最近は Emacs の設定まわりや、AI / LLM 関連の話題が多くなってきた。興味が生成AI絡みのことに向くようになってきたので、自然とそちらに引っ張られている感じ。技術トレンドは移り変わりが速いので、自分の中で整理する意味でも、こうして書いておくのは悪くないと思っている。書きながら考えがまとまることも、わりとある。

ちなみに今のワークフローは、Emacs の Org-mode でざっくり書いて、ox-hugo で変換して Hugo でビルドする構成。保存すれば自動でエクスポートされるようになったので、だいぶ楽になった。以前は「書く気はあるのに、投稿するまでの手順が面倒」ということがあったけれど、今はそのあたりのフリクションがほとんどなくなっている。

細々とでも続いているのは、自分のためのメモとして機能しているからだと思う。数年前に書いた設定を見返して「あー、こんなことをやっていたな」となるのが、意外と悪くない。誰かの役に立てばそれはそれで嬉しいけれど、まずは自分のための場所として、これからものんびり続けていくつもり。
